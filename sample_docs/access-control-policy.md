# Access Control Policy (SAMPLE — fictional)

Document ID: AC-POL-001
Standard: ISO 27001 (illustrative, not official text)

## AC-1 Password requirements
All user passwords must be at least 12 characters long and include one number and one
symbol. Passwords must be rotated every 90 days.

## AC-2 Multi-factor authentication
Multi-factor authentication (MFA) is required for all administrator accounts and for any
remote access to production systems.

## AC-3 Account lockout
User accounts must be locked after 5 consecutive failed login attempts. Locked accounts
can only be released by the IT help desk.
